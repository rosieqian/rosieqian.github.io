# Security Audit: Controls & Compliance

## Project summary

I completed a security audit of Botium Toys, a fictional organization used in the Google Cybersecurity Professional Certificate. I reviewed its security controls and considered alignment with PCI DSS, GDPR, and SOC practices.

## Key findings

- Access to sensitive information should be limited through least privilege and stronger user-access policies.
- Customer and payment-card data needs encryption and safer handling throughout storage, processing, and transmission.
- Stronger password policies and password-management practices are needed.
- Intrusion detection, tested backups, and disaster-recovery planning would improve detection and resilience.
- Better asset inventory and regular maintenance or replacement of legacy systems would reduce exposure.

## Recommendations

Prioritize access control, encryption, password security, intrusion detection, backups, and disaster recovery. Follow with stronger asset tracking and a plan for legacy systems. These changes would lower risk and improve alignment with PCI DSS, GDPR, and SOC expectations.

## Skills demonstrated

- Audit scoping
- Security-control assessment
- Risk prioritization
- Compliance awareness
- Written recommendations for stakeholders

## Reflection

This activity reinforced that an audit is not complete when gaps are identified. Findings must be translated into clear priorities that account for business impact, compliance obligations, and practical implementation.

> This project uses a fictional training scenario and contains no employer, customer, or confidential data.
